# Grok Build Desktop 0.5.39

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.39 đưa skill Grok cục bộ và Chrome DevTools MCP vào workspace Desktop để agent biết cách kiểm tra UI, dùng MCP và chạy cổng phát hành. Các tệp Windows chưa được ký số. | Release 0.5.39 adds local Grok skills and Chrome DevTools MCP to the Desktop workspace so the agent can verify UI, use MCP and run the release gate. The Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Workspace có `.grok/skills` (`/verify-ui`, `/use-mcp`, `/write-fix-log`, `/run-check`) hiện trong menu `/` của Desktop. | The workspace ships `.grok/skills` (`/verify-ui`, `/use-mcp`, `/write-fix-log`, `/run-check`) in the Desktop `/` menu. |
| `.grok/rules/00-workspace.md` luôn nạp: Desktop là surface, engine là Grok CLI, UI phải được kiểm chứng. | `.grok/rules/00-workspace.md` always loads: Desktop is the surface, Grok CLI is the engine, and UI work must be verified. |
| `.grok/config.toml` bật Chrome DevTools MCP cho kiểm tra trang web sống. Electron vẫn dùng `npm run check:visual`. | `.grok/config.toml` enables Chrome DevTools MCP for live web pages. Electron still uses `npm run check:visual`. |

## Gói phát hành / Release artifacts

- `Grok-Build-Setup-0.5.39.exe` — NSIS Setup / Bộ cài NSIS
- `Grok-Build-0.5.39-win32-x64-portable.exe` — Portable executable / Bản portable EXE
- `Grok-Build-0.5.39-win32-x64.zip` — Portable ZIP / Bản ZIP giải nén
- `MANIFEST.json` — Sizes and SHA-256 / Kích thước và SHA-256

| Tiếng Việt | English |
|---|---|
| Các tệp Windows chưa được ký Authenticode và có thể kích hoạt cảnh báo SmartScreen. Hãy kiểm tra SHA-256 trong `MANIFEST.json` trước khi chạy. | The Windows artifacts are not Authenticode-signed and may trigger SmartScreen. Verify SHA-256 values in `MANIFEST.json` before running them. |
