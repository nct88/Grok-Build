## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Căn chỉnh giao diện hội thoại Desktop theo Codex: các panel trung tính, vùng đọc căn giữa, dòng suy luận/công cụ gọn, tin nhắn người dùng căn phải và composer nổi. | Aligns the Desktop conversation surface with Codex: neutral panes, centered reading width, compact thought/tool rows, right-aligned user messages and a floating composer. |
| Giữ đúng thứ tự trực tiếp `suy luận → công cụ → trả lời` và khôi phục an toàn các mục `reasoning.summary_text` của Grok CLI khi mở lại session; nội dung suy luận mã hóa không bao giờ được gửi đến renderer. | Preserves live `thought → tool → answer` order and safely restores Grok CLI `reasoning.summary_text` entries when reopening sessions; encrypted reasoning content never reaches the renderer. |
| Trong lúc streaming, câu trả lời được giữ ở dạng văn bản ổn định; sau khi hoàn tất mới render thành Markdown có cấu trúc mà không quay lại các marker thô. | Keeps streaming responses as stable plain text, then renders finalized responses as structured Markdown without reverting to raw markers. |
| Plan, công cụ/diff và review sử dụng bề mặt phẳng; bảng Markdown giữ khung vuông bên ngoài và đường kẻ ô. | Uses flat Plan, tool/diff and review rows; Markdown tables retain a square outer frame and cell grid. |
| Tự ẩn panel phải tùy chọn ở chiều rộng 1180 CSS pixel trở xuống và khôi phục khi cửa sổ rộng hơn. | Hides the optional right panel at 1180 CSS pixels and below, restoring it when the window becomes wider. |
| Nhận diện đường dẫn tuyệt đối và tương đối theo project trong câu trả lời hoàn tất, đánh dấu màu xanh và hỗ trợ mở/điều hướng/sao chép qua menu chuột phải đã được bảo vệ. | Detects absolute and project-relative paths in finalized answers, highlights them in blue and supports reveal/open/copy actions through the guarded context menu. |
