## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Đồng bộ thư mục dự án giữa bộ chọn dưới composer, sidebar, tab đang hoạt động và session được khôi phục; lịch sử chat không còn tự gắn vào dự án đang chọn sai. | Synchronizes the project folder across the composer picker, sidebar, active tab and restored session so chat history is not attached to the wrong selected project. |
| Thêm chức năng di chuyển chat hiện có sang dự án khác và cập nhật đồng thời dữ liệu session cùng metadata tóm tắt. | Adds moving an existing chat to another project while updating both session data and summary metadata. |
| Việt hóa nhãn Tool/Review động khi giao diện dùng tiếng Việt. | Localizes dynamic Tool/Review labels when the interface uses Vietnamese. |
| Cải thiện liên kết file/thư mục cục bộ, hỗ trợ đường dẫn có khoảng trắng và hậu tố dòng mã; thư mục được mở đúng bằng hành động hệ thống. | Improves local file/folder links, including paths with spaces and source-line suffixes; directories now open through the proper system action. |
| Thêm menu chuột phải trong nội dung session để sao chép phần chọn, sao chép toàn bộ hoặc chọn toàn bộ. | Adds a session context menu for copying the selection, copying all content or selecting all. |
| Điều chỉnh dependency đóng gói để electron-builder không duyệt junction npm trên Windows; runtime bundle vẫn được đưa vào `resources/packages`. | Adjusts packaging dependencies so electron-builder does not traverse npm junctions on Windows; runtime bundles remain included in `resources/packages`. |
