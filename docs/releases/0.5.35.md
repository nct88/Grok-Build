# Grok Build Desktop 0.5.35

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản phát hành 0.5.35 được chuẩn bị ngày 13-08-2026 sau khi gắn chat vào dự án bên trái, gọn tiêu đề session và cho phép mở nhiều thư mục trong một cuộc trò chuyện. Các tệp Windows chưa được ký số. | Release 0.5.35 was prepared on 2026-08-13 after binding chats to the sidebar project, compacting the session header, and allowing multiple source folders in one conversation. The Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Chọn dự án không còn tạo tab Chat thừa; lịch sử nằm dưới dự án bên trái. | Opening a project no longer creates leftover Chat tabs; history stays under the sidebar project. |
| Thanh tab session ẩn khi chỉ có một cuộc trò chuyện; Chat mới đi từ sidebar. | The session tab rail is hidden for a single conversation; new chats start from the sidebar. |
| Tiêu đề session bỏ hash git và nút Create PR. | The session header no longer shows the git hash or Create PR. |
| Hộp thoại Mở dự án cho phép thêm nhiều thư mục nguồn vào cùng một chat. | The Open project dialog can attach multiple source folders to the same chat. |
