# Grok Build Desktop 0.5.38

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.38 bám Grok CLI 1.0.5: truyền mức suy luận khi mở/resume ACP, hiện recap/lượt gần nhất, và bổ sung các lệnh `/` phổ biến. Các tệp Windows chưa được ký số. | Release 0.5.38 tracks Grok CLI 1.0.5: reasoning effort is supplied when an ACP session opens or resumes, recap/last-turn summaries appear in Desktop, and common slash commands are available. The Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| `session/new` và `session/load` gửi `_meta.reasoningEffort` (CLI 1.0.5) thay vì chỉ dựa vào cờ `--reasoning-effort` lúc spawn. | `session/new` and `session/load` send `_meta.reasoningEffort` (CLI 1.0.5) instead of relying only on the spawn `--reasoning-effort` flag. |
| Danh sách chat, dải ngữ cảnh trên header và `/session-info` hiện last-turn summary cùng recap phiên khi CLI đã ghi chúng. | The chat list, header context strip and `/session-info` show last-turn summaries and session recaps when the CLI has written them. |
| Menu `/` thêm các lệnh phổ biến của TUI: `/new`, `/context`, `/compact`, `/recap`, `/rewind`, `/copy`, `/export`, `/rename`, `/model`, `/effort`, `/plan`, `/btw`, `/docs`, `/doctor` và alias (`/clear`, `/undo`, `/status`, `/summarize`). | The `/` menu adds common TUI commands: `/new`, `/context`, `/compact`, `/recap`, `/rewind`, `/copy`, `/export`, `/rename`, `/model`, `/effort`, `/plan`, `/btw`, `/docs`, `/doctor` and aliases (`/clear`, `/undo`, `/status`, `/summarize`). |
| Spinner công cụ đang chuẩn bị dùng nhãn dễ đọc (Writing file…, Writing edit…) và tiêu đề phiên tự làm mới sớm nếu chưa bị `/rename` ghim. | Preparing tool spinners use readable labels (Writing file…, Writing edit…) and session titles refresh early unless pinned by `/rename`. |
