# Grok Build Desktop 0.5.36

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.36 nâng cấp nội dung phiên theo Grok CLI 1.0.3, tách rõ Session, Context và Account. Các tệp Windows chưa được ký số. | Release 0.5.36 upgrades session details to match Grok CLI 1.0.3 and clearly separates Session, Context and Account. The Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Hiển thị tiêu đề, phiên bản CLI, phương thức xác thực, Session ID, thư mục làm việc, model, API backend, sandbox, số lượt, mức suy luận và chế độ quyền. | Shows the title, CLI version, authentication method, Session ID, working directory, model, API backend, sandbox, turn count, reasoning effort and permission mode. |
| Tab Context hiển thị tổng token, input/output, cache, reasoning, số lần gọi model, thời gian API và chi phí ngay cả khi dịch vụ billing không khả dụng. | The Context tab shows total, input/output, cache and reasoning tokens, model calls, API time and cost even when account billing is unavailable. |
| Có thể bấm từng dòng để sao chép hoặc dùng Copy all; bố cục đã được kiểm tra ở 1000×640 và 1440×900. | Every row can be clicked to copy, with a Copy all action; layouts were verified at 1000×640 and 1440×900. |
| Dữ liệu xác thực nhạy cảm không được chuyển qua IPC; giao diện chỉ nhận tên phương thức xác thực. | Sensitive authentication data never crosses IPC; the interface receives only the authentication method label. |
