## P0 corrections

- Release scripts reject an existing version and never prune old versions.
- Missing portable, installer, update, payload, or VSIX files fail publishing.
- `MANIFEST.json` and `latest.json` contain portable relative paths rather than build-machine drive paths.
- `-PublicRelease` requires an HTTPS base URL and valid Authenticode signatures. Local artifacts are explicitly marked unsigned candidates.
- Desktop at 1000×640 keeps a 747 px conversation and 708 px composer; the tools drawer does not cover header actions or composer.
- IDE fills the viewport at 240×720, 390×720, 600×900, and 600×900 at 150% DPI.
- IDE identity is consistently **Grok Build IDE** in product metadata, extension, executable, installer, and artifact names.

## Verification evidence

- Desktop: architecture, packaging, release contract, 24 integration/security tests, source visual and packaged visual passed.
- IDE: typecheck, production build, 58 tests, release contract, four visual scenarios, single-file cache repair, registry/settings, runtime/CDP, folder reuse, installer install/launch passed.
- SHA-256 validation passed for every manifest artifact in both releases.
- Production dependency audit: 0 known vulnerabilities for both shipped applications.

## External publication gates

The local candidates are not public releases. Code signing credentials and an HTTPS/CDN release base are external requirements; rerun each publisher with `-PublicRelease -ReleaseBaseUrl https://...` after signed artifacts are available.
