# Grok Build Desktop 0.5.30

Local unsigned release candidate prepared on 2026-08-11.

## Highlights

- Aligns the Desktop conversation surface with Codex: neutral panes, centered reading width, compact thought/tool rows, right-aligned user messages and a floating composer.
- Preserves live `thought → tool → answer` order and restores safe Grok CLI `reasoning.summary_text` entries when reopening sessions; encrypted reasoning content never reaches the renderer.
- Keeps streaming responses as stable plain text, then renders finalized responses as structured Markdown without reverting to raw markers.
- Uses flat Plan, tool/diff and review rows; Markdown tables retain a square outer frame and cell grid.
- Hides the optional right panel at 1180 CSS pixels and below, restoring it when the window becomes wider.
- Detects absolute and project-relative paths in finalized answers, highlights them in blue and supports reveal/open/copy actions through the guarded context menu.
