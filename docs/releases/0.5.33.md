# Grok Build Desktop 0.5.33

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản phát hành 0.5.33 được chuẩn bị ngày 13-08-2026 sau khi đồng bộ dự án/chat, thêm cập nhật Grok CLI tự động và chỉnh bố cục composer. Các tệp Windows chưa được ký số. | Release 0.5.33 was prepared on 2026-08-13 after project/chat synchronization, automatic Grok CLI update detection and composer layout changes. The Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Chọn dự án trong khung chat giữ đúng thư mục đang mở sau khi gửi tin; lịch sử xuất hiện dưới dự án bên trái. | Opening a project in the chat frame stays bound after send, and the new chat appears under that sidebar project. |
| Ứng dụng phát hiện phiên bản Grok CLI mới và model mới, rồi thông báo để nhấn cập nhật bằng `grok update`. | The app detects newer Grok CLI versions and models, then offers a one-click `grok update`. |
| Usage nằm ngay sau Effort trên composer; bấm vào hiện cùng thông tin như Cài đặt, phần Usage trong Settings vẫn giữ. | Usage sits next to Effort in the composer and opens the same usage details as Settings, which remain available. |
| Effort hỗ trợ `low` / `medium` / `high` / `xhigh` (mặc định `high`; `xhigh` cho grok-4.6+); chip model không còn chữ `(default)`. | Effort supports `low` / `medium` / `high` / `xhigh` (default `high`; `xhigh` on grok-4.6+); the model chip no longer shows `(default)`. |
| Bộ chọn thư mục dự án chuyển lên góc trên bên trái khung chat. | The project folder picker moves to the top-left of the chat frame. |
